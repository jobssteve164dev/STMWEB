# STMWEB

面向 STM32 智能硬件的浏览器调试工作台实验原型。

## 已实现的实验闭环

- 统一入口连接串口、USB、HID 调试探针、蓝牙和局域网设备。
- 自动检测当前浏览器能力，只在用户发起连接时请求系统授权。
- 接收并展示实时调试输出和遥测数据。
- 将调试会话与全部事件写入 IndexedDB，刷新页面后仍可查询并导出 JSON。
- 导入 `.bin`、`.hex`、`.elf`、`.axf`、`.srec` 固件，计算 SHA-256 后连同原文件保存为独立版本。
- 以工作区、设备台账、固件版本和会话记录组织调试数据。
- 无硬件时可以运行明确标识的演示会话，验证记录链路而不操作真实设备。

## 本地运行

需要 Node.js 22 和 Chromium 系浏览器：

```bash
npm install
npm run dev
```

然后访问 `http://127.0.0.1:5173`。本机开发地址属于浏览器安全上下文；通过域名部署时必须使用 HTTPS，USB、串口、HID 和蓝牙授权发生在访问者自己的电脑上，而不是 Homelab 服务器上。

## Verify

```bash
npm run check
npm audit --audit-level=high
```

生产构建输出到 `dist/`，可由任意静态 Web 服务托管。

## 当前边界

这是用于验证浏览器能力、用户连接动作和本地数据链路的实验原型。它尚未实现 ST-Link/J-Link/OpenOCD 等真实探针协议、固件烧录、断点与寄存器读写，也没有服务端账号、跨电脑同步和对象存储。后续接入本地连接器时，前台仍应保留同一个“连接设备”入口，让浏览器直连与连接器差异停留在实现层。
